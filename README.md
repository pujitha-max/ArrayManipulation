# Array Manipulation

## Overview

This project contains Java programs for basic array manipulation.

The programs can:

* Find the smallest and largest elements in an integer array.
* Reverse the elements of an array.

## Programs

1. ArrayMinMax.java
2. ReverseArray.java

## Technologies Used

* Java
* Scanner
* Arrays
* Loops

## How to Run

1. Open the project in IntelliJ IDEA.
2. Make sure JDK 21 or above is installed.
3. Run `ArrayMinMax.java` to find the smallest and largest elements.
4. Run `ReverseArray.java` to reverse the array.
5. Enter the number of elements and the array elements when asked.

## Example

Input:
5

10 20 30 40 50

Output:

* Smallest element: 10
* Largest element: 50
* Reversed array: 50 40 30 20 10
